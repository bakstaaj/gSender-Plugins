# CNC Camera Monitor Local Bridge
**Latest release package:** [Download camera-monitor-local-bridge-v0.1.0.zip](https://github.com/bakstaaj/gSender-Plugins/releases/download/camera-monitor-local-bridge-v0.1.0/camera-monitor-local-bridge-v0.1.0.zip)

The current Windows companion package is [version 0.1.0](v0.1.0/README.md). It runs go2rtc outside gSender and turns compatible ONVIF/RTSP sources into a browser-playable WebRTC view for CNC Camera Monitor.

![Camera Monitor feed displayed over the gSender Carve visualizer](v0.1.0/screenshots/carve-view.png)

Download `camera-monitor-local-bridge-v0.1.0.zip` from the [version folder](v0.1.0/) or the matching GitHub Release. Extract it, run **Install Camera Bridge.cmd**, then configure and name streams from the plugin’s **Configure cameras** panel. The detailed [setup guide](v0.1.0/README.md) includes ONVIF discovery, manual RTSP examples, two-camera naming, and troubleshooting.
