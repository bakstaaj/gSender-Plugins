# 3D Part Mapping v0.1.11 — machine-test release

**Release package:** [Download the v0.1.11 install ZIP](https://github.com/bakstaaj/gSender-Plugins/releases/download/surface-perimeter-mapper-v0.1.11/surface-perimeter-mapper-v0.1.11.zip)

This version changes both DXF exporters to minimal R12 DXF files for compatibility with strict importers. The 2D perimeter uses classic `POLYLINE`/`VERTEX` entities; the 3D output uses an indexed polyface mesh. R12 does not store an explicit unit setting, so select millimeters when importing. The previous R2000-format candidate was not displayed by QCAD; please test this R12 output in your target CAD application.

The surface-planning limit remains 15,000 points. Outside-perimeter-only scans plan just the one surface-height touch required to set the model top; they do not calculate the interior surface grid.

DXF export offers a 2D perimeter drawing or a 3D model. The 2D option writes the compensated outer boundary and detected cutout outlines as closed R12 polylines at actual millimeter coordinates. The 3D option writes a deduplicated R12 indexed polyface with coordinates enlarged by 100× to keep short edges distinct. The earlier R2000-format 3D file was rejected by SketchUp, and earlier DXFs were not displayed by QCAD; the new R12 format has not yet been confirmed in those applications. Do not use the enlarged 3D DXF coordinates for machining.

When hard limits are enabled ($21=1), the plugin subtracts the controller-reported homing pull-off ($27) from configured axis travel before calculating machine bounds and the probe-length limit. It then applies the existing 0.5 mm probe-boundary margin.

This package enables the contact-driven workflow on a connected controller. It has been tested with a simulated controller, including GRBL-format probe reports and signed machine coordinates, and on a physical CNC machine. Different controllers and probes can behave differently, so use caution when testing. Probe deflection, missed contacts, controller timing, workholding and inaccessible or ambiguous features can affect the result.

Use a homed machine with G54 selected, a verified probe signal and a controller that supports G38.2, G38.3, G10 L20 and the position/status reports used by gSender. The plugin interprets GRBL $23 as a homing-direction invert mask: clear axis bits home toward positive machine coordinates, while set bits home toward negative coordinates. For example, $23=7 means X, Y and Z home in the negative direction. The plugin uses that sign together with $130–$132 to calculate machine-coordinate travel limits; verify those limits match the machine. The test build supports positive-up Z and requires sufficient Z travel for L + 1 mm above the bed. Probe contacts release with a normal rapid backoff; the workflow does not use G38.5.

Enter the probe tip diameter D, usable thin-shaft length L, spacing and feeds. The part must be no thicker than L. Position the probe over exposed bed at least one tip diameter in front of the part and select **Start Probe**. After the probe-signal check, the machine probes the bed, changes G54 X, Y and Z zero to the bed-contact position, retracts directly to 0.75D above the bed and begins the perimeter automatically. Save any G54 offsets you need before starting.

Choose **Outside perimeter only** to trace the perimeter and take one surface-height touch; its STL is a closed, flat-topped perimeter solid from the bed to that touch. **Inside surface only** traces the same perimeter for its boundary, then maps the surface and exports an open surface mesh without exterior or bed walls. **Both perimeter and surface** runs the full map and exports the closed model. In Results, the Display and STL view selector changes the visible mesh and the copied/downloaded STL together; views that need surface data stay unavailable after a perimeter-only scan. A short informational completion dialog appears when a scan finishes.

The first bed probe uses the adjusted Z travel bound, including the configured homing pull-off when hard limits are enabled, and remains 0.5 mm inside that bound. Each subsequent downward probe move is limited to L; full clearance is L + 1 mm above the measured bed and is used after the perimeter. Perimeter corner refinement, including Ultra precise, stays at the established bed-clearance height and does not retract to L between corner samples. After a perimeter or raised-feature wall contact, the plugin waits for the controller to settle with the probe triggered, retracts with a normal rapid move, and extends the retract in checked increments if needed. Surface XY moves are guarded; new contacts can initiate a perimeter trace for a raised feature or pocket. Sampling and geometry compensation are approximate; the STL uses estimated edges and a bed-level bottom.

Recovery behavior is automatic where the controller state makes the next move unambiguous. If a bed touch has no probe report, the plugin waits briefly for a delayed report and requests fresh status; it may return vertically to the recorded bed-probe start and retry once at the slow feed only after confirming the machine is homed and idle, the XY position is unchanged, and the probe input is clear. If a perimeter contact remains active after the first retract, the plugin extends the retract in checked 0.25D steps up to 3D total. Ambiguous failures save the successful contacts and show an error dialog with an always-available Exit Scan control. On the next Start Probe, choose to continue from the saved checkpoint or start a new scan. Continuing automatically raises to safe full-clearance machine Z, returns to the saved bed-probe position, re-probes the bed, then returns at clearance to the saved scan checkpoint before proceeding. For recoverable scan pauses, the dialog provides jog controls; they remain locked until a fresh, homed Idle status arrives. Continue also requires a known-clear probe input and operator acknowledgement. Non-recoverable workflow errors show explanatory text and an always-available Exit Scan button, without jog or Continue controls.

Stay with the machine and be ready to use its physical stop. The plugin's **Stop after current move** button requests a stop after the current command; it is not an emergency stop. Stop the test if any position, direction, probe behavior or clearance is unexpected.


DXF export is available alongside STL and RAW CSV export. The 2D option writes closed polylines for the compensated outer perimeter and detected cutout boundaries in true millimeters. The surface-only view exports an open surface; perimeter-only and combined views retain their corresponding 3D geometry.
