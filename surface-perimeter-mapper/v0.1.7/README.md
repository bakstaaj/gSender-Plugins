# 3D Part Mapping v0.1.7

**Release package:** [Download the v0.1.7 install ZIP](https://github.com/bakstaaj/gSender-Plugins/releases/download/surface-perimeter-mapper-v0.1.7/surface-perimeter-mapper-v0.1.7.zip)

The initial bed probe now ends 0.5 mm inside the configured Z travel boundary to avoid a soft-limit Alarm 2.

This package enables the contact-driven workflow on a connected controller. It has been tested with a simulated controller, including GRBL-format probe reports and signed machine coordinates, and on a physical CNC machine. Different controllers and probes can behave differently, so use caution when testing. Probe deflection, missed contacts, controller timing, workholding and inaccessible or ambiguous features can affect the result.

Use a homed machine with G54 selected, a verified probe signal and a controller that supports G38.2, G38.3, G10 L20 and the position/status reports used by gSender. The plugin interprets $23 and $130–$132 as its machine-coordinate travel limits; verify those limits match the machine. The test build supports positive-up Z and requires sufficient Z travel for L + 1 mm above the bed. Probe contacts release with a normal rapid backoff; the workflow does not use G38.5.

Enter the probe tip diameter D, usable thin-shaft length L, spacing and feeds. The part must be no thicker than L. Position the probe over exposed bed at least one tip diameter in front of the part and select **Start Probe**. After the probe-signal check, the machine probes the bed, changes G54 X, Y and Z zero to the bed-contact position, retracts directly to 0.75D above the bed and begins the perimeter automatically. Save any G54 offsets you need before starting.

Choose **Outside perimeter only** to trace the perimeter and take one surface-height touch; its STL is a closed, flat-topped perimeter solid from the bed to that touch. **Inside surface only** traces the same perimeter for its boundary, then maps the surface and exports an open surface mesh without exterior or bed walls. **Both perimeter and surface** runs the full map and exports the closed model. In Results, the Display and STL view selector changes the visible mesh and the copied/downloaded STL together; views that need surface data stay unavailable after a perimeter-only scan. A short informational completion dialog appears when a scan finishes.

The first bed probe endpoint is limited to 0.5 mm inside the configured Z travel limit to avoid targeting the soft-limit boundary. Each subsequent downward probe move is limited to L; full clearance is L + 1 mm above the measured bed and is used after the perimeter. Perimeter corner refinement, including Ultra precise, stays at the established bed-clearance height and does not retract to L between corner samples. After a perimeter or raised-feature wall contact, the plugin waits for the controller to settle with the probe triggered, retracts with a normal rapid move, and extends the retract in checked increments if needed. Surface XY moves are guarded; new contacts can initiate a perimeter trace for a raised feature or pocket. Sampling and geometry compensation are approximate; the STL uses estimated edges and a bed-level bottom.

Recovery behavior is automatic where the controller state makes the next move unambiguous. If a bed touch has no probe report, the plugin waits briefly for a delayed report and requests fresh status; it may return vertically to the recorded bed-probe start and retry once at the slow feed only after confirming the machine is homed and idle, the XY position is unchanged, and the probe input is clear. If a perimeter contact remains active after the first retract, the plugin extends the retract in checked 0.25D steps up to 3D total. Ambiguous failures save the successful contacts and show an error dialog with an always-available Exit Scan control. On the next Start Probe, choose to continue from the saved checkpoint or start a new scan. Continuing automatically raises to safe full-clearance machine Z, returns to the saved bed-probe position, re-probes the bed, then returns at clearance to the saved scan checkpoint before proceeding. In the controller-recovery dialog, jog and Continue remain locked until a fresh Idle report arrives; Exit Scan remains available.

Stay with the machine and be ready to use its physical stop. The plugin's **Stop after current move** button requests a stop after the current command; it is not an emergency stop. Stop the test if any position, direction, probe behavior or clearance is unexpected.
