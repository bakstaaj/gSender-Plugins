Camera protocol notes
  • USB: uses the computer camera permission and browser media capture.
  • HTTP MJPEG: displays a multipart JPEG stream directly as an image.
  • JPEG snapshots: reloads one JPEG URL at the selected rate.
  • WebSocket JPEG: receives binary JPEG frames and can send a start message. The Makera Z1 preset uses this mode.
  • Browser video URL: works only for formats supported by this Chromium build, such as compatible MP4/WebM streams. HLS support varies.
  • RTSP: browsers do not play RTSP directly. Restream it locally as MJPEG, browser-playable video, or WebRTC before using this plugin.

Camera manufacturers use different paths, codecs, and authentication. The gSender computer must be allowed to reach the camera, and the camera must accept connections from gSender’s plugin view.
