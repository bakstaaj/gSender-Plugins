1. Map setup

Set Length X and Width Y to cover the complete project toolpath from the captured origin. Use values equal to or larger than the project’s machine-coordinate X and Y extents; compensation stops if any move falls outside the mapped area.

Probe type

If gSender reports the machine already homed, the plugin uses the current machine Z as its retract baseline; confirm that Z is clear and safe before moving. Start calibration moves to the entered map start X/Y while preserving Z, captures the resulting machine position as the map origin, then begins probing. After the final probe, the plugin retracts to machine Z0, then parks at machine X0 Y0. The map must fit within the controller’s reported machine travel.

3. Compensate a G-code file

The plugin creates a new compensated file and loads it into gSender’s visualizer. It leaves the selected original untouched. On Apply, it aligns the selected file’s smallest X/Y coordinates to the captured map origin by updating saved G54 X/Y. This persistent offset also affects other G54 jobs until changed again. The file must use metric, absolute G0/G1 moves and fit inside the map.
