Bundled Windows x64 runtimes

Node.js v24.21.0
- Source archive: https://nodejs.org/download/release/v24.21.0/node-v24.21.0-win-x64.zip
- The portable node.exe is included for the background event monitor. npm is not required on the target computer.
- Node.js and bundled third-party license notices are in NODE-LICENSE.txt.

NSSM 2.24-101-g897c7ad (x64)
- Source archive: https://nssm.cc/ci/nssm-2.24-101-g897c7ad.zip
- Upstream license: public domain. See NSSM-README.txt.
- Upstream recommends this build on Windows 10 and newer to avoid a service startup issue in the 2.24 stable build.

Windows PowerShell 5.1 is provided by Windows 10 and newer and is not redistributed in this package.
